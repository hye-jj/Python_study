# movie_crawling 
- 영화목록 정보 출처 : KOBIS 영화정보 (https://www.kobis.or.kr/kobis/business/mast/mvie/searchMovieList.do)


## 개요
해당 프로젝트는 네이버 영화리뷰 정보제공이 종료되어,            
2023년 이후의 영화에 대해 영화리뷰(관람평)을 수집하기 위해 만들어졌습니다.

## 수행과제
-  영화리뷰 데이터 확인, 형태소 분석, 전처리
-  LDA 토픽모델링
-  LSTM, GRU 모델 감성분석


### 영화 데이터 크롤링 및 리뷰 감성분석
① 프로젝트 목표  <br>
영화 관련 웹 데이터를 직접 수집하고, 수집한 리뷰 데이터를 전처리하여 영화에 대한 사용자 의견과 감성을 분석하는 데이터 분석 과정 학습 <br>
 <br>
② 담당 역할 <br>
Python을 활용한 영화 및 리뷰 데이터 크롤링 <br>
크롤링 데이터 전처리 및 분석 <br>
영화 리뷰 텍스트를 활용한 감성분석 수행 <br>
분석 결과 및 주요 특징 확인 <br>
 <br>
③ 사용 기술 <br>
Python · Requests · BeautifulSoup · Pandas · 자연어처리(NLP) · 감성분석 <br>
 <br>
④ 주요 수행내용 <br>
웹 크롤링을 통한 영화 관련 데이터 및 리뷰 수집 <br>
수집한 텍스트 데이터의 정제 및 전처리 <br>
영화 리뷰를 긍정·부정 등 감성 데이터로 분류 <br>
리뷰 데이터를 기반으로 영화에 대한 사용자 반응 분석 <br>
감성분석 결과를 활용하여 영화별 평가 및 리뷰 특징 확인 <br>
 <br>
⑤ 결과 / 배운점 <br>
웹 크롤링을 통해 직접 데이터를 수집하고,  <br>
데이터 전처리 → 텍스트 분석 → 감성분석으로 이어지는 데이터 분석 과정을 경험했습니다. <br>
또한 비정형 텍스트 데이터를 분석 가능한 형태로 변환하고,  <br>
리뷰에 나타난 사용자 의견을 데이터 기반으로 파악하는 방법을 학습했습니다. <br>
