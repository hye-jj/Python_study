### 건축물대장 파일 다운로드
* 건축물대장 파일 위치 : 건축물대장 민간개방 시스템(https://open.eais.go.kr/opnsvc/opnSvcInqireView.do)
![image](https://github.com/user-attachments/assets/eaa10959-21cb-432b-9829-de1bb1acedbf)

  
* 2024년 10월 기준 로그인없이 파일 다운로드 가능
* 11개 파일 다운로드 시간 오래걸려서 프로그램 실행해서 다운로드하기

* 파이썬 환경
* 폴더다운받고 가상환경만들기
* pip install -r requirements.txt (필수패키지 설치)
* start.bat 파일 실행 (가상환경 위치 변경되었으면 바꿔주기)
