## 🛒 이커머스 랜딩페이지 A/B 테스트 프로젝트

> **신규 랜딩페이지 디자인이 고객 구매 전환율에 미치는 영향 분석**
>
> *무결성 검증(SRM 검정), Z-검정, 벡터화 부트스트랩, 효과크기(Cohen's h) 측정 및 비즈니스 의사결정 프로세스를 포함한 데이터 분석 파이프라인 프로젝트입니다.*

<br>

### 📌 프로젝트 개요 (Executive Summary)

본 프로젝트는 이커머스 플랫폼의 기존 랜딩페이지(`old_page`)와 신규 랜딩페이지(`new_page`)의 성과를 비교하여, 신규 디자인 전면 적용 여부를 데이터 기반으로 결정하기 위해 진행되었습니다.

* **최종 분석 데이터 크기**: 총 294,478건 원본 로그 $\rightarrow$ 중복 및 트래킹 오류 정제 후 **290,584명의 유니크 유저**
* **대조군 (Control, 기존 페이지) 전환율**: **12.04%**
* **실험군 (Treatment, 신규 페이지) 전환율**: **11.88%**
* **통계 검정 결과**: Two-Sample Z-Test ($Z = -1.3109$, 양측 $p = 0.1899$)
* **최종 결론**: **귀무가설($H_0$) 채택**. 신규 랜딩페이지 도입에 따른 전환율 상승 효과가 관찰되지 않았습니다. **(권장 사항: 신규 페이지 적용 보류 및 원인 분석 후 재설계)**

<br>
 

### 📂 데이터셋 구조

본 분석 데이터는 Kaggle의 [E-commerce A/B Testing Dataset](https://www.kaggle.com/datasets/zhangluyuan/ab-testing)을 활용했습니다.

| 컬럼명 (Column) | 데이터 타입 | 설명 |
| :--- | :--- | :--- |
| `user_id` | `int64` | 유저 고유 식별 번호 |
| `timestamp` | `object` | 페이지 접속 시간 |
| `group` | `object` | 실험 할당 그룹 (`control` 또는 `treatment`) |
| `landing_page` | `object` | 노출된 랜딩페이지 버전 (`old_page` 또는 `new_page`) |
| `converted` | `int64` | 전환 여부 (`1`: 구매/전환 성공, `0`: 미전환) |

<br>
 

### 🧪 실험 설계 및 가설 설정

#### 1. 가설 설정

* **귀무가설 ($H_0$)**: $p_{new} \le p_{old}$
  *(신규 랜딩페이지의 전환율은 기존 랜딩페이지보다 높지 않다.)*
* **대립가설 ($H_1$)**: $p_{new} > p_{old}$
  *(신규 랜딩페이지의 전환율이 기존 랜딩페이지보다 높다.)*

#### 2. 주요 실험 파라미터

* **핵심 지표 (Target Metric)**: 전환율 ($\frac{\text{전환 유저 수}}{\text{총 접속 유저 수}}$)
* **유의수준 ($\alpha$)**: $0.05$ (5%)
* **그룹 목표 할당 비율**: $1:1$ ($50\%$ Control, $50\%$ Treatment)

<br>
 

### 🧹 데이터 전처리 및 무결성 검증

#### 1. 그룹-페이지 불일치 데이터 제거
시스템 오류나 트래킹 버그로 인해 `control` 그룹에 `new_page`가 노출되거나, `treatment` 그룹에 `old_page`가 노출된 행을 검출하여 정제했습니다.
* **제거된 불일치 데이터**: 3,893건

#### 2. 중복 유저 정제
동일 유저가 여러 번 접속한 기록을 필터링하여 각 유저의 **첫 번째 접속 기록만 유지**함으로써 독립성(i.i.d.) 조건을 충족했습니다.

#### 3. SRM (Sample Ratio Mismatch) 검정
가설 검정 수행 전, 유저가 목표 비율($1:1$)대로 무작위 배정되었는지 카이제곱 적합도 검정(Chi-Square Goodness-of-Fit Test)으로 정량 검증했습니다.

* **카이제곱 통계량 ($\chi^2$)**: $0.0013$
* **p-value**: $0.9712$ ($p > 0.01$)
* **SRM 검정 결과**: **통과 (PASSED)**. 샘플 배정 편향이나 시스템 왜곡이 없음을 확인했습니다.

<br>
 
### 📊 통계 분석 및 주요 결과
#### 1. 그룹별 전환율 요약

| 구분 | 그룹 | 분석 유저 수 ($N$) | 전환 유저 수 | 전환율 ($p$) |
| :--- | :--- | :--- | :--- | :--- |
| **Control (대조군)** | `old_page` | 145,274명 | 17,489명 | **12.04%** |
| **Treatment (실험군)** | `new_page` | 145,310명 | 17,264명 | **11.88%** |

#### 2. 2-Sample Z-Test 결과
전환 여부는 이항분포를 따르므로 2-Sample Z-Test를 통해 두 그룹 간 전환율 차이의 통계적 유의성을 검정했습니다.

* **합성 표준오차 ($SE$)**: $0.0012$
* **Z-통계량**: $-1.3109$
* **p-value**: `0.1899` (양측검정) / `0.0950` (단측검정)
* **해석**: 유의수준 $\alpha = 0.05$ 기준에서 $p > 0.05$이므로, 관찰된 $-0.16\%p$의 전환율 차이는 **통계적으로 유의미하지 않습니다**.

#### 3. 벡터화 부트스트랩 (2,000회 반복)
정규성 가정에 의존하지 않고 두 그룹의 전환율 차이 $(\text{Treatment} - \text{Control})$ 분포를 직접 추정하기 위해 부트스트랩 리샘플링을 수행했습니다.

* **평균 전환율 차이**: $-0.158\%p$
* **95% 부트스트랩 신뢰구간**: `[-0.395%p, +0.078%p]`
* **해석**: 95% 신뢰구간 내에 $0$이 포함되므로, 신규 랜딩페이지가 더 우수하다고 단정할 수 없습니다.

#### 4. 효과크기 (Cohen's h)

* **Cohen's h**: $-0.0048$
* **기준표**: 작음 = $0.2$, 중간 = $0.5$, 큼 = $0.8$
* **해석**: 효과크기가 $0.2$ 미만으로 매우 작아 **실질적 비즈니스 임팩트(Practical Significance)가 없습니다**.

<br>

#### 💡 최종 결론 및 비즈니스 제언

1. **최종 의사결정: 신규 페이지 배포 보류 (Rollback)**
   * 신규 랜딩페이지는 기존 대비 전환율 개선을 이끌어내지 못했으며, 오히려 소폭 하락했습니다. 전면 적용 시 플랫폼 매출에 긍정적인 영향이 없을 것으로 판단됩니다.

2. **원인 추적 및 향후 과제**
   * **초기 피로도 / 이질감 (Novelty Effect)**: 기존 유저가 개편된 UI/UX에 적응하지 못했거나, 핵심 행동 유도 버튼(CTA)의 시각적 위계가 약화되었을 가능성이 있습니다.
   * **세그먼트 세분화 분석**: 접속 기기(모바일 vs 데스크톱), 사용자 유형(신규 유저 vs 재방문 유저)별 세그먼트 분석을 추가 진행하여 특정 그룹에서 반등 요소가 있는지 확인해야 합니다.

3. **분석 방법론적 성과**
   * SRM 사전 검정을 통해 데이터 수집상의 바이아스를 제거하고 분석 결과의 신뢰도를 확보했습니다.
   * 약 29만 명의 충분한 표본 크기를 확보하여 검정력(Statistical Power) 부족으로 인한 2종 오류 발생 가능성을 방지했습니다.
